# Дизайн-стандарт OmnesAgent ADE (Design System Specification)

> **Статус**: Официальный стандарт дизайн-системы OmnesAgent (Desktop & Web).  
> **Версия**: 2.0.0 (Unified Cyber-Minimal Standard).  
> **Цель**: Обеспечение абсолютной визуальной гармонии, предсказуемости интерфейса, идентичных отступов и строгой унификации всех выпадающих меню, поповеров, модальных окон и компонентов управления.

---

## 1. Философия и дизайн-код: Cyber-Minimal Titanium

Дизайн-система OmnesAgent ADE объединяет лучшие практики современных сред разработки (**shadcn/ui**, **Linear**, **Raycast**, **Cursor**, **VS Code**) с кибернетической эстетикой Omnes:
1. **Информационная плотность и чистота**: интерфейс профессионального инструмента разработчика. Никаких гигантских пустых пространств («воздуха ради воздуха») или декоративных элементов, мешающих фокусу.
2. **Предсказуемость пространственной геометрии**: все размеры кратны базовой сетке (4px/8px). Одинаковые элементы обязаны иметь одинаковые внешние и внутренние отступы, высоту и скругления.
3. **Единое поведение оверлеев**: все выпадающие списки, контекстные меню и плавающие карточки строятся по **единому шаблону позиционирования и оформления**.
4. **Контрастная монохромная основа с акцентным неоном**:
   - Глубокие графитовые фоны (Zinc / Slate);
   - Тонкие и чёткие границы 1px;
   - Точечный электрический акцент **Electric Cyan (`#00D2FF`)** и семантические статусы (зелёный/красный/янтарный).
5. **Строгий запрет эмодзи в элементах интерфейса**: вместо эмодзи (`📁`, `⚙️`, `📂`) используются исключительно векторные иконки (`Icons.folder_outlined`, `FontAwesomeIcons`).

## 3. Цветовая палитра и иерархия слоёв (Surfaces & Colors)

Интерфейс строится по принципу **4 уровней высоты (Elevation Layers)**. Каждый слой контрастирует с предыдущим за счёт цвета и 1px границы.

### 3.1. Иерархия слоёв (Surfaces)

| Слой | Название | Dark Theme (HEX) | Light Theme (HEX) | Описание |
|---|---|---|---|---|
| **L0** | **App Shell / Canvas** | `#141619` / `#16181D` | `#F1F5F9` / `#FFFFFF` | Глобальный фон окна и подложка чата |
| **L1** | **Surface / Panels** | `#1B1D22` | `#F8FAFC` | Сайдбар, инспектор, контекстная строка проекта |
| **L2** | **Elevated / Cards** | `#20242D` | `#FFFFFF` | Карточки сообщений, кнопки, инпуты, чипы |
| **L3** | **Overlay / Popover** | `#1B1D22` / `#22262E` | `#FFFFFF` | Выпадающие меню, поповеры, диалоговые окна |

### 3.2. Границы и разделители (Borders)

- **`border-subtle`**: `rgba(255, 255, 255, 0.08)` / `#22262E` (Dark), `#E2E8F0` (Light). Базовые границы панелей и карточек.
- **`border-medium`**: `#2C323E` (Dark), `#CBD5E1` (Light). Границы кнопок и полей ввода при наведении (Hover).
- **`border-focus` / `border-active`**: `#00D2FF` (Electric Cyan, 1px или 1.5px). Фокус ввода, активный выбор, открытые выпадающие меню.

### 3.3. Текст и контрастность (Typography Colors)

- **`text-primary`**: `#FFFFFF` (Dark), `#0F172A` (Light) — заголовки, активные значения, основной текст ответов.
- **`text-secondary`**: `#CBD5E1` (Dark), `#475569` (Light) — текст пунктов меню, подписи, лейблы кнопок.
- **`text-muted`**: `#8B949E` / `#64748B` (Dark), `#94A3B8` (Light) — подсказки (placeholders), метаданные, шорткаты.
- **`text-code`**: `#38BDF8` (Dark), `#0284C7` (Light) — моноширинный код, ветки Git, теги.

### 3.4. Семантические статусы (Semantic Colors)

- **Success / Добавления Git (`+`)**: `#10B981` (Emerald). Используется для добавленных строк (`+129`), успешных проверок и галочек `✓`.
- **Destructive / Удаления Git (`-`)**: `#EF4444` (Red). Используется для удаленных строк (`-42`), ошибок терминала и опасных действий («Удалить сессию»).
- **Warning / Ожидание**: `#F59E0B` (Amber). Ожидание одобрения, пауза агента, предупреждения линтера.
- **Accent Cyan / Бренд**: `#00D2FF`. Главный фокус, бейджи активных проектов, подсветка синтаксиса, шевроны.

## 4. ГЛОБАЛЬНЫЙ СТАНДАРТ: Выпадающие меню, поповеры и списки действий

> [!IMPORTANT]
> **Главное правило интерфейса**: Все выпадающие меню в OmnesAgent ADE должны иметь **идентичную геометрию, единую типографику, одинаковый оффсет от триггера и предсказуемую логику позиционирования**. Запрещено задавать хардкодные экранные координаты вроде `top: 76, right: 14` без привязки к вызывающему элементу.

### 4.1. Классификация выпадающих элементов

В системе OmnesAgent ADE существует ровно **3 типа оверлеев**:

```
┌────────────────────────────────────────────────────────────────────────┐
│ ТИП 1: Action Dropdown (Меню действий: 3 точки, контекстное меню)     │
│ [Пункт 1      ]  Высота пункта: 32px                                   │
│ [Пункт 2      ]  Иконка: 13-14px (#94A3B8 -> #00D2FF)                 │
│ [Пункт 3  Ctrl]  Шорткат: 10px Consolas                                │
├────────────────────────────────────────────────────────────────────────┤
│ ТИП 2: Selector Menu (Выбор значения: Модель, Провайдер, Ветка)       │
│ [✓ Значение 1 ]  Ширина: 220–280px                                     │
│ [  Значение 2 ]  Чекмарк: Icons.check (#00D2FF) справа                │
│ [+ Создать... ]  Кнопка добавления внизу                               │
├────────────────────────────────────────────────────────────────────────┤
│ ТИП 3: Popover Card (Инфо-карточка: Git Tools, Таск-бар, Календарь)   │
│ ┌ Заголовок ─────────────── [x] ┐  Ширина: 340–380px                  │
│ │ Метрики / списки / чеклисты   │  Паддинг: 14px                      │
│ └───────────────────────────────┘  Тень: blur 16, offset (0, 6)       │
└────────────────────────────────────────────────────────────────────────┘
```

### 4.2. Правила позиционирования (Trigger Anchoring)

1. **Вертикальный зазор (Gap)**: строго **4–6px** между границей триггера и выпадающим окном.
2. **Направление раскрытия**:
   - **Триггеры в верхней панели / строке контекста** (Бейджи изменений, Таск-бар, Ветка Git, Проект): открываются **вниз** (`Offset(0, 4)`).
   - **Триггеры в нижней панели (Composer)** (Выбор провайдера, выбор модели, уровень рассуждений, режим подтверждения): открываются **вверх** (`Offset(0, -6)`).
3. **Горизонтальное выравнивание**:
   - Если триггер находится в **левой половине** экрана: левый край меню выравнивается по левому краю триггера (`alignment: Alignment.topLeft`).
   - Если триггер находится в **правой половине** экрана (как плашки изменений и таск-бара): **правый край меню строго выравнивается по правому краю триггера** (`alignment: Alignment.topRight`).
4. **Контроль краев экрана (Viewport Clamping)**: меню никогда не должно выходить за пределы окна. При приближении к краю оно автоматически сдвигается внутрь на `8px`.

### 4.3. Визуальный стиль контейнера выпадающего окна

```dart
// Единый BoxDecoration для всех оверлеев и поповеров:
BoxDecoration(
  color: DesktopTheme.isDark ? const Color(0xFF1B1D22) : Colors.white,
  borderRadius: BorderRadius.circular(8), // 8px для меню, 10px для карточек
  border: Border.all(
    color: DesktopTheme.isDark ? const Color(0xFF282D37) : const Color(0xFFE2E8F0),
    width: 1.0,
  ),
  boxShadow: [
    BoxShadow(
      color: Colors.black.withOpacity(DesktopTheme.isDark ? 0.45 : 0.15),
      blurRadius: 16,
      offset: const Offset(0, 6),
    ),
  ],
)
```

### 4.4. Стандарт элемента выпадающего списка (`MenuItem`)

Каждый пункт выпадающего меню обязан строго соблюдать следующие параметры:

- **Высота**: ровно **32px** (для компактных меню) или **36px** (для селекторов моделей/веток).
- **Внутренние отступы**: `padding: EdgeInsets.symmetric(horizontal: 10, vertical: 0)`.
- **Скругление ховера**: `borderRadius: BorderRadius.circular(5)`.
- **Цвет при наведении (Hover)**:
  - Dark: `Color(0xFF242933)` или `Color(0xFF00D2FF).withOpacity(0.08)`.
  - Light: `Color(0xFFF1F5F9)`.
- **Иконка слева**:
  - Размер: **13–14px**;
  - Цвет: `#94A3B8` (при ховере / активности: `#00D2FF`);
  - Правый отступ: `8px`.
- **Текст пункта**:
  - Шрифт: системный (`Segoe UI` / `Inter`);
  - Размер: **12px**;
  - Цвет: `#E2E8F0` (Dark) / `#0F172A` (Light);
  - Начертание: `FontWeight.w500` (для выбранного: `FontWeight.w600`).
- **Индикатор выбора / Действие справа**:
  - Для селекторов: иконка `Icons.check` (размер 13px, цвет `#00D2FF`).
  - Для шорткатов: текст шрифтом `Consolas`, `fontSize: 10.5px`, цвет `#64748B`.
- **Разделители (Dividers)**:
  - Толщина: `1px`;
  - Высота блока: `8px` (`Divider(height: 8, thickness: 1, color: borderSubtle)`).

## 6. Типографика и шрифтовая иерархия

Интерфейс использует строгую двухшрифтовую систему:
1. **Пропорциональный шрифт UI**: `Segoe UI` (Windows), `-apple-system` (macOS), `Inter` / `Roboto` (Linux/Web).
2. **Моноширинный шрифт кода**: `Consolas` / `JetBrains Mono` / `Fira Code`. Применяется **всегда** для:
   - Временных меток и счетчиков времени (`0:14s`);
   - Диффов и изменений кода (`+129 -1`);
   - Имен веток Git (`main`, `feat/ade-split`);
   - Путей к файлам (`frontend/desktop/...`);
   - Хоткеев (`⌘K`, `Shift+Enter`);
   - Счетчиков токенов (`28.4k tokens`).

## 7. Каталог стандартных компонентов (Component Specifications)

### 7.1. Кнопки (Buttons)

- **Primary Button (Акцентная)**:
  - Фон: `Color(0xFF00D2FF).withOpacity(0.18)` (Dark) / `Color(0xFF0284C7)` (Light).
  - Текст/Иконка: `Color(0xFF00D2FF)` (Dark) / `Colors.white` (Light), `FontWeight.bold`.
  - Рамка: 1px `Color(0xFF00D2FF)`.
  - Ховер: мягкое усиление свечения (Glow `rgba(0, 210, 255, 0.25)`).
- **Secondary Button (Обычная)**:
  - Фон: `DesktopTheme.bgSurfaceElevated`.
  - Рамка: 1px `DesktopTheme.borderSubtle`.
  - Текст: `DesktopTheme.textPrimary`.
- **Ghost / Icon Button**:
  - Фон: `Colors.transparent`.
  - Ховер: `DesktopTheme.borderSubtle.withOpacity(0.5)`.
  - Размер кликабельной области: минимум `22×22px` до `28×28px`.

### 7.2. Плашка изменений (Review Pill)

Эталонная плашка по скриншоту референса:
```
┌─────────────────────────────────────────────────────────────┐
│ 4 files changed  +129 -1  >                       📄 Review │
└─────────────────────────────────────────────────────────────┘
```
- **Контейнер**: фон `#16181D`, скругление `8px`, рамка 1px `#282D37`, тень `blurRadius: 6, offset: (0, 2)`.
- **Отступы**: `EdgeInsets.symmetric(horizontal: 14, vertical: 8)`.
- **Текст изменений**:
  - Текст `{N} files changed `: `13px`, `#E2E8F0`.
  - `+{additions} `: `13px`, шрифт `Consolas`, цвет `#4ADE80`.
  - `-{deletions} `: `13px`, шрифт `Consolas`, цвет `#F87171`.
  - Шеврон `>`: `14px`, `#64748B`.
- **Кнопка Review**: фон `#222732`, рамка `#333A48`, скругление `6px`, иконка `Icons.description_outlined` (`13px`), текст `Review` (`12px`, `#E2E8F0`).

### 7.3. Поле ввода (Composer / Prompt Box)

- Плавающий контейнер внизу центрального холста с отступами `horizontal: 24px, bottom: 16px`.
- Скругление: `10px`.
- Фон: `#181B20` (Dark) / `#FFFFFF` (Light).
- Рамка: 1px `#282D37`, при фокусе — `#00D2FF`.
- Тень: мягкая тень парения над чатом `blurRadius: 16, offset: (0, 4)`.

### 7.4. Таблицы данных и Markdown-таблицы (Data Tables & Markdown Tables)

Все таблицы в ответах агента, инспекторе и отчетах оформляются в едином стиле кибер-терминала:
```
┌────────────────────────────────────────────────────────────────────────┐
│ Ветка                  │ Действие                      │ Результат     │ (Шапка: 32px, bgSurfaceElevated)
├────────────────────────┼───────────────────────────────┼───────────────┤ (1px borderSubtle)
│ [feat/ade-split]       │ коммит [b4e91c7] + пуш        │ synced ✓      │ (Строка: 30px, zebra subtle)
│ [feat/blast-radius]    │ пуш [9c3e711]                 │ synced ✓      │
│ [main]                 │ пуш не требуется              │ behind 2 ⚠    │
└────────────────────────────────────────────────────────────────────────┘
```
- **Контейнер**:
  - Скругление: `8px` (`radius-lg`), с `Clip.antiAlias`.
  - Граница: 1px `borderSubtle`.
  - Внешний отступ: `margin: EdgeInsets.symmetric(vertical: 8)`.
  - Горизонтальная прокрутка (`SingleChildScrollView(scrollDirection: Axis.horizontal)`) для широких колонок, предотвращающая переполнение чата.
- **Строка заголовков (Header Row)**:
  - Высота: `32–34px`.
  - Фон: `DesktopTheme.bgSurfaceElevated` (`#20242D` Dark / `#F8FAFC` Light).
  - Разделитель: нижняя граница 1px `borderSubtle`.
  - Текст: `12px`, `FontWeight.w600`, цвет `textPrimary` (`#FFFFFF` / `#0F172A`).
  - Паддинг ячейки: `EdgeInsets.symmetric(horizontal: 12, vertical: 8)`.
- **Строки данных (Data Rows)**:
  - Зебра-окраска: четные строки прозрачные, нечетные строки с легкой заливкой `DesktopTheme.bgSurfaceElevated.withOpacity(0.35)`.
  - Разделитель: нижняя граница 0.8px `borderSubtle.withOpacity(0.5)`.
  - Высота строки: минимум `30–32px`.
  - Паддинг ячейки: `EdgeInsets.symmetric(horizontal: 12, vertical: 7)`.
  - Текст ячейки: `12px`, с поддержкой инлайн-чипов кода (fontFamily `Consolas`, фон `#22262E`, цвет `#38BDF8`, скругление `4px`), семантических цветов статуса (зеленый `#10B981`, желтый `#F59E0B`, красный `#EF4444`).

## 8. Анимации и микровзаимодействия (Motion Guidelines)

1. **Длительности (Durations)**:
   - **Микро-отклик (Hover, Нажатие, Подсветка)**: `100–120ms`.
   - **Открытие/закрытие меню и поповеров**: `150–200ms`.
   - **Раскрытие аккордеона мыслей / Таск-бара**: `250ms`.
   - **Смена экрана / Вкладки**: `200ms` с плавным `Fade`.
2. **Кривые анимации (Curves)**:
   - Открытие оверлеев: `Curves.easeOutCubic`.
   - Закрытие оверлеев: `Curves.easeInCubic`.
   - Сворачивание/разворачивание списков: `Curves.fastOutSlowIn`.

## 9. Чек-лист соответствия для каждого нового компонента

Перед сдачей любого изменения в интерфейсе проверяется:
- [ ] Все отступы соответствуют 4px/8px шкале (никаких нечетных случайных цифр).
- [ ] Все выпадающие меню открываются с зазором 4–6px от триггера и выравниваются по краю триггера.
- [ ] В меню используются стандартные пункты высотой 32px/36px со скруглением ховера 4–6px.
- [ ] Для моноширинных данных (диффы, ветки, пути, тайминги) используется шрифт `Consolas`.
- [ ] Деструктивные действия и минусовые изменения (`-`) окрашены в красный `#EF4444`, добавления (`+`) — в зеленый `#10B981`.
- [ ] В тултипах и строках отсутствуют эмодзи папок и значков — используются строгие векторные иконки.
- [ ] Все выпадающие списки и модальные окна закрываются по клику вне области и по клавише `Escape`.
