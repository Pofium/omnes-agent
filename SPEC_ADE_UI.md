# Спецификация и Архитектурный План Развития OmnesAgent ADE (Desktop & Web)

Настоящий документ представляет собой структурированную спецификацию изменений интерфейса (UI/UX) и шлюза бэкенда (`omnesagent-gateway`), объединяющую все утвержденные требования и доработки.

---

## 1. Стилизация и Светлая Тема (Light Mode UI)

- **Контрастность кнопок**:
  - В светлой теме основные кнопки действий (включая главную кнопку **«+ Новая сессия»** в боковом меню) имеют плотную, непрозрачную заливку цвета `#0F172A` (угольно-черный оттенок shadcn/ui) и четкий белый текст `#FFFFFF`.
  - Исключен размытый/серый стиль кнопок в светлой теме, нарушающий визуальную иерархию.
- **Цветовые токены** (`desktop_theme.dart`):
  - `btnPrimaryBg`: `#0F172A` (Light) / `#282D37` (Dark).
  - `btnPrimaryText`: `#FFFFFF`.

---

## 2. Панель Изменений Git и Контекст Групп/Проектов

- **Условия отображения**:
  - Бейдж **«Изменения +X -Y»** отображается в верхней панели рабочего пространства **только если активная сессия/проект имеет Git-репозиторий** (`hasGitRepo == true`).
  - Для сессий вне репозиториев (например, быстрые черновики или задачи в группе «Разное» без привязанного проекта) бейдж автоматически скрывается.
- **Контекстное окно Git Tools**:
  - Удалена лишняя кнопка с тремя точками (`Icons.more_horiz`).
  - Плашка информации сверху динамически отображает:
    - Активный проект и привязанную группу: `📁 [Имя проекта]` + бейдж группы.
    - Ветку из активной сессии без хардкода (`activeBranch ?? 'main'`).
    - Динамический чеклист прогресса и задач, соответствующий выбранной кодовой базе.

---

## 3. Интеграция Сессий с Шлюзом Бэкенда

- **Хранилище сессий**:
  - База данных SQLite шлюза: `~/.omnesagent/data/sessions/sessions.db`.
  - Таблицы: `session_metadata` и `sessions`.
- **Реальные сессии по умолчанию**:
  1. `omnes-core-arch` — **«Архитектура ядра OmnesAgent»** (проект `Omnes agent`, ветка `feat/ade-split`, группа «Работа»).
  2. `deepseek-v3-eval` — **«Тестирование инференса DeepSeek»** (проект `Omnes agent`, ветка `desktop-brand-ru`, группа «Работа»).
- **Синхронизация**:
  - Клиент загружает сессии по протоколу REST `GET /api/sessions` и подключается к живому стримингу сообщений через WebSocket `GET /api/sessions/{id}/ws`.
  - Моковые демо-задачи (`omnes-1`, `amo-1`, `proxy-1`) удалены.

---

## 4. Сохранение Кастомных LLM-Провайдеров

- **Проблема**: При пересборке или перезапуске приложения добавленные пользователем кастомные OpenAI-совместимые провайдеры пропадали.
- **Решение**:
  - Реестр кастомных провайдеров сохраняется в локальное хранилище `GetStorage` по ключу `custom_providers_registry`.
  - При сохранении конфигурации настройки дублируются в `config.toml` шлюза:
    ```toml
    [model_providers.<provider_id>]
    name = "Custom Provider"
    base_url = "https://api.custom.ai/v1"
    api_key = "sk-..."
    default_model = "model-name"
    max_concurrency = 8
    ```
  - В интерфейс настроек добавлена кнопка безопасного удаления провайдера.

## 5. Изменяемый Размер Панелей (Resizable Split Layout)

- **Разделители**:
  - Между левым сайдбаром и центральной рабочей областью добавлен перетаскиваемый мышью разделитель с курсором `resizeColumn`. Ширина сайдбара: `200..440px` (по умолчанию `260px`).
  - Между центральной рабочей областью и правым инспектором добавлен разделитель. Ширина инспектора: `280..650px` (по умолчанию `420px`).

---

## 6. Организация Групп и Создание Проектов

- **7 групп по умолчанию**:
  1. **Разное** (основная группа по умолчанию, без привязанного Git-репозитория).
  2. **Дом**
  3. **Работа** (содержит проекты `Omnes agent`, `dsh-desktop`).
  4. **Семья**
  5. **Развлечения**
  6. **Поездки и путешествия**
  7. **Временное**
- **Мини-меню групп**:
  - Создание новой сессии (`+`).
  - Контекстное меню (`···`): переименование, выбор одной из 20 иконок, привязка папки артефактов и проекта.
- **Создание проекта**:
  - Всплывающее окно: Название, Папка на диске, Тематика (домен).
  - Автоматический подбор и предпросмотр рекомендованных агентов, тулзов и навыков (skills) для выбранного домена кодовой базы.

---

## 7. Дерево Файлов Проекта и Просмотрщик (File Viewer)

- В карточке проекта доступна кнопка `[ 📂 ]` перехода к дереву файлов.
- При нажатии сайдбар переключается в режим файлового дерева проекта с кнопкой возврата `[ ← К проектам ]`.
- Клик по файлу открывает его в правом инспекторе во вкладке **File Viewer** с нумерацией строк, подсветкой и отображением относительного пути.

---

## 8. Динамические Вкладки Инспектора (Lazy Tool Tabs)

- Вкладки в заголовке инспектора:
  - `Live Browser` (WebView2 / Web Browser)
  - `Terminal` (псевдотерминал)
  - `Canvas` (Live Canvas A2UI)
  - `Preview` (Review & Diff)
  - `Side Chat` (дополнительный контекстный диалог)
  - `File Viewer` (просмотрщик файлов проекта)
- Каждая открытая вкладка оснащена кнопкой закрытия `[x]`.
- При закрытии всех вкладок или по нажатию на иконку панелей открывается экран выбора вкладки (**Open tab**).
