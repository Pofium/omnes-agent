# Omnes Agent — Мобильный и Десктопный клиент (Flutter)

Кроссплатформенный клиент для автономной агентной платформы **Omnes Agent** (ZeroClaw), построенный на Flutter. Поддерживает потоковый чат через WebSocket с живым reasoning, файловый менеджер проектов, выбор агентов, долгосрочную память, планировщик Cron, мониторинг токенов/затрат и голосовое управление.

---

## 📁 Архитектура проекта (Feature-First)

Исходный код организован по модульному принципу **Feature-First**: каждая функциональная область изолирована в своей папке и содержит экраны, контроллеры (GetX), модели и виджеты.

```
OmAgent-front/
├── lib/
│   ├── core/                        # Инфраструктурное ядро
│   │   ├── gateway/                 # WebSocket клиент, REST HTTP клиент, конфигурация шлюза
│   │   └── supabase/                # Интеграция Supabase (профили, настройки, промпты)
│   ├── features/                    # Модули функционала (Feature-First)
│   │   ├── agents/                  # Диалог и управление активным агентом
│   │   ├── approvals/               # Одобрение / отклонение опасных действий агента
│   │   ├── auth/                    # Авторизация и профиль пользователя (LoginScreen)
│   │   ├── chat/                    # Потоковый чат, reasoning, markdown, голосовой ввод
│   │   ├── cron/                    # Управление фоновыми расписаниями и триггерами
│   │   ├── files/                   # Проекты, просмотр файлов и PDF
│   │   ├── home/                    # Главный экран (Dashboard), боковое меню Drawer
│   │   ├── memory/                  # Долгосрочная память агента (ключ-значение)
│   │   ├── profile/                 # Редактирование профиля пользователя
│   │   ├── sessions/                # История и переключение сессий
│   │   ├── settings/                # Настройки шлюза, Bearer токена, языка и TTS
│   │   ├── splash/                  # Стартовый экран загрузки
│   │   ├── stats/                   # Аналитика расходов, токенов и моделей
│   │   ├── support/                 # Поддержка и обратная связь
│   │   └── system_status/           # Статус сервера Omnes и шлюза
│   ├── helper/                      # Утилиты: локальное хранилище (GetStorage), TTS, загрузка
│   ├── routes/                      # Маршрутизация (GetX Routes & Pages)
│   ├── utils/                       # Цвета, размеры, темы и мультиязычность (RU, EN...)
│   ├── widgets/                     # Общие UI виджеты (кнопки, поля ввода, markdown)
│   └── main.dart                    # Точка входа приложения
├── scripts/                         # Скрипты автоматизации в один клик
│   ├── build_apk.ps1                # Сборка Android APK (Debug / Release)
│   ├── run_app.ps1                  # Запуск приложения на устройстве или Windows
│   └── check_health.ps1             # Проверка анализатора (analyze) и запуск тестов
└── test/                            # Полный набор юнит- и виджет-тестов
```

## 🚀 Быстрый запуск и сборка «В один клик»

В папке `scripts/` подготовлены удобные PowerShell скрипты:

### 1. Сборка Android APK
```powershell
# Быстрая сборка Debug APK (по умолчанию):
.\scripts\build_apk.ps1

# Сборка Release APK:
.\scripts\build_apk.ps1 -Mode Release
```
*Скрипт автоматически проверит окружение, замерит время сборки и выведет путь к собранному `.apk` и его размер в МБ.*

### 2. Запуск приложения
```powershell
# Автоматический выбор доступного устройства / эмулятора:
.\scripts\run_app.ps1

# Запуск на Windows Desktop:
.\scripts\run_app.ps1 -Device windows
```

### 3. Комплексная проверка здоровья (Анализ + Тесты)
```powershell
.\scripts\check_health.ps1
```
*Запускает `flutter analyze --no-pub` и `flutter test --no-pub` с понятным цветовым отчетом.*

## ⌨️ Запуск по клавише F5 (VS Code / Antigravity IDE)

В проекте настроен файл `.vscode/launch.json`. Для запуска и отладки:
1. Откройте проект в VS Code или Antigravity IDE.
2. Нажмите клавишу **F5** (или перейдите во вкладку *Run & Debug*).
3. Выберите конфигурацию:
   - `Omnes Agent (Debug)`
   - `Omnes Agent (Release)`

## ⚙️ Настройка подключения к шлюзу Omnes Gateway

По умолчанию клиент подключается к локальному шлюзу Omnes:
- **HTTP/WS URL**: `http://127.0.0.1:42617` (WebSocket: `ws://127.0.0.1:42617`)
- **Bearer Token**: `omnes-token-secret-12345`
- **Default Agent**: `chief`

Изменить адрес сервера и токен авторизации можно прямо в приложении:
**Экран «Настройки» (иконка шестеренки в верхнем правом углу)** -> Введите URL и токен -> Нажмите кнопку **«Проверить шлюз»** -> Сохраните.
